# Publish the repository on GitHub

1. Extract the supplied ZIP into a folder. Open the extracted folder and locate README.md alongside model/, data/, results/, scripts/ and docs/.
2. Sign in to GitHub and create a new repository named `pscad-three-phase-fault-study`.
3. Suggested description: `PSCAD study of an 11 kV feeder: three-phase faults, breaker command-delay comparison, I²t analysis and time-step sensitivity.`
4. Choose Public if you want recruiters to see it. Do not initialise it with another README or .gitignore; these are supplied.
5. On the new repository page choose Upload an existing file. Upload the extracted repository contents, preserving the folders. Upload README.md at the repository root, not inside an extra enclosing folder. Include the supplied .gitignore (hidden files may need to be shown locally). Upload the extracted files rather than the ZIP as your main repository content.
6. Commit with a message such as `Add PSCAD feeder fault study and verified results`.
7. Open the repository page. Confirm that the README displays its charts and that the native project, seven raw CSV files and analysis script are visible.
8. Pin the repository on your GitHub profile and add its link to your CV or applications.

The archive excludes generated build files and the PSCAD Master Library. Each user needs their own PSCAD installation. No repository has been created or published automatically by preparing this package.

Before an interview, run the model yourself and practise the questions in interview-notes.md. Add a PSCAD schematic screenshot to the README if desired; the existing diagram is a conceptual diagram, not a screenshot of the native drawing.
